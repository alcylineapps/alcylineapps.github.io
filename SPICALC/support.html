よくある質問

データはどこに保存されますか？

すべてお使いの端末の中に保存され、外部には送信しません。機種変更の前に「設定」＞「バックアップを書き出す」で控えを作り、「ファイル」アプリの iCloud Drive などに保存してください。新しい端末では「バックアップから復元」で戻せます。

無料体験はどうなっていますか？

はじめて SPICALC Pro を申し込む方は、1週間無料でお試しいただけます。無料期間が終わる24時間前までに解約しなければ、年額7,000円で自動更新されます。無料体験は1つの Apple ID につき1回までです。

Pro を解約するには？

iPhone / iPad の「設定」＞ Apple ID ＞「サブスクリプション」から解約できます。更新日の24時間前までに解約すると、次の更新は行われません。解約後も、期間が終わるまでは Pro をお使いいただけます。登録したデータは、解約しても消えません。

機種を変えたら Pro が使えなくなりました

アプリの「設定」＞「SPICALC Pro」＞「購入を復元」を押してください。購入時と同じ Apple ID でサインインしている必要があります。

売れ残りアラートの通知が来ません

アプリの「設定」＞「売れ残りアラートの通知」がオンになっているか、iPhone / iPad の「設定」＞「通知」＞ SPICALC で通知が許可されているかをご確認ください。通知は、仕入れ日から各段階の日数（初期値は30・60・90日。「設定」＞「売れ残りの段階と値下げ提案」で変更できます）になった日の朝9時に届きます（Pro の機能です）。

売れ残りアラートの日数や値下げ率を変えたい

「設定」＞「売れ残りの段階と値下げ提案」で、3つの段階それぞれの日数と値下げ率を変えられます（第1＜第2＜第3 の日数にしてください）。変更すると、通知の予定と値下げ提案の価格がすぐに切り替わります。

販売手数料の率が実際と違います

「設定」＞「販路と手数料率」で変更できます。各サービスの最新の料率に合わせてください。

使っている販路がありません／使わない販路を消したい

「設定」＞「販路と手数料率」の「販路を追加」で、名前・手数料率・色を決めて追加できます（手渡しや店頭販売など、手数料がない販路は0%に）。使わない販路は「削除」で選択肢から外せます。削除しても、その販路で登録済みの商品はそのまま残り、集計にも入ります。「削除した販路を戻す」で元に戻せます。

ほかのアプリや Excel から取り込むには？

元のデータを CSV で書き出し、在庫画面の「＋」を長押し＞「CSVから取り込む」（または「設定」＞「CSVから取り込む」）で読み込んでください。列の見出しから中身を自動で判断し、取り込む前に内容を確認できます。文字コードは UTF-8 と Shift_JIS に対応しています。

収支レポートだけで確定申告できますか？

収支レポートは、登録したデータを集計した資料です。収支内訳書や青色申告決算書に書き写すときにお使いください。申告の内容は、税務署や税理士の案内に沿ってご確認ください。
