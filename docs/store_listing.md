**説明**
```
親が倒れたとき、救急隊に持病や飲んでいる薬、いつもの様子を伝えられますか？

ALDECARE（アルデケア）は、家族の救急情報をまとめておき、もしものときにすぐ伝えるためのアプリです。本人が話せないときや、家族がその場にいないときでも、スマホが代わりに伝えます。
最初は、名前・生年月日・緊急連絡先の3つだけ。1分で準備できます。

■ 救急隊に「いつもの本人」を伝える
持病・飲んでいる薬（市販薬やサプリも）・アレルギー・かかりつけ医・緊急連絡先を、白地に黒の大きな文字で表示します。
救急の現場で知りたいのは、病名だけではありません。いつもの話し方や歩き方、もの忘れの程度、平熱、補聴器や入れ歯の有無、延命治療についての本人の希望も残しておけます。

■ ロックしたままでも見られる
救急情報をロック画面用の画像にします。ロックを解除しなくても、救急隊が情報を見られます。出す項目は自分で選べます。

■ 最後に元気だった時刻
「いま元気です」を押すと時刻が残ります。急に具合が悪くなったとき、いつまで元気だったかを伝える手がかりになります。

■ 119番に電話するとき
住所・目印・本人の名前と年齢・持病など、伝えることを順番に表示し、マナーモードでも読み上げます。慌てていても、順番に伝えられます。

■ 救急車を呼ぶか迷ったら
お住まいの地域の救急相談（#7119）と、子どもの急な病気の相談（#8000）に電話できます。#8000 は全47都道府県に対応しています。
※#7119 の窓口がない地域もあります。命に関わるときは、迷わず119番へ。

■ 病院の問診票や、救急医療情報キットにも
初めての病院の問診票を書くときも、アプリを開けば持病や薬を見ながら書けます。項目を押すとコピーもできます。市区町村が配っている「救急医療情報キット」の用紙は、書く内容を1項目ずつ大きく表示するので、プリンターがなくても書き写すだけで準備できます。

■ データはスマホの中だけ
登録した情報はこの端末の中だけに保存し、サーバーには送りません。アカウント登録もいりません。

【Pro版（買い切り）】
・家族の分も登録：離れて暮らす親や子どもの情報も、1つのアプリでまとめて管理
・ロック画面に自動で反映：情報を変えたら、ボタン1つでロック画面も新しく（ショートカットアプリを使います）
・いつもの体力を記録：椅子立ち上がり・片足立ち・歩く速さを月に1回ほど測ってグラフにします。これまでより下がったら目安としてお知らせし、家族に送ることもできます

救急隊に見せる画面・119番の補助・救急相談・問診票・書き写しガイド・ロック画面用の画像の保存は、無料でずっと使えます。

【ご注意】
・このアプリは、情報の記録・共有と目安の表示のためのものです。病気やフレイルの診断はしません。
・受診の判断は医師にご相談ください。命に関わるときは、迷わず119番に電話してください。
・救急隊がこのアプリの情報を必ず確認するとは限りません。
・救急相談の電話番号は、消防庁・厚生労働省の公表資料（2026年11月確認）にもとづいています。番号や受付時間は変わることがあります。
・電話は、ご自身で発信ボタンを押してかけます。

Developed by Tadashi / Alcyline
```

**データセーフティ（Play Console）**
- データの収集：なし／データの共有：なし
- 理由：入力した情報は端末内だけに保存。インターネットの権限を使っていないので、外に送る通信がない

- 「データの収集」：**いいえ（データは収集されません）**
- 理由：開発者のサーバーはなく、入力した情報は端末内だけ。通信するのは App Store の課金だけ

## 年齢区分の質問票
- 医療や治療に関する情報の項目があれば「まれ／軽度」。ほかはすべて「なし」
- 理由：医療情報は利用者が自分で入力して表示するだけで、アプリが治療の助言をするものではない。体力の記録も、本人の過去の記録と比べた目安を出すだけ

## 審査メモ（App Review への連絡事項・英語でそのまま貼る）
```
ALDECARE is a family emergency-information app for Japan (Japanese UI). It lets users keep their own or a family member's medical information (conditions, medications, allergies, usual condition, emergency contacts) on the device, and show it to paramedics. No account or login is required.

This app is not a medical device. It does not diagnose, give treatment advice or measure vital signs. It only stores and displays what the user enters. The "usual fitness" records (chair stands, one-leg standing, walking speed) are timed by the user and compared only with the user's own past records, as a reference. The screens show a notice to consult a doctor and to call 119 in an emergency.

How to review:
1. On first launch, enter any name (e.g. "Test") and tap the button under the form (これで作る). The screen for paramedics (救急情報) appears.
2. Home > 本人カード: add conditions, medications and emergency contacts. Home > 救急隊に見せる shows them in large text.
3. Home > 119に通報する: shows what to say on a 119 call and reads it aloud (AVSpeechSynthesizer). The call button opens the standard iOS call confirmation; you do not need to place a call.
4. Home > 救急相談: phone numbers of the Japanese medical consultation lines (#7119 / #8000) for the prefecture chosen in the profile. iOS cannot dial numbers starting with "#", so the app uses the regular numbers each prefecture publishes for the same service.
5. Home > ロック画面に表示: creates an image of the emergency information and saves it to an album in Photos (photo library permission). The user can set it as the lock screen wallpaper.
6. Pro (sandbox purchase of "ALDECARE Pro", product ID com.alcyline.aldecare.pro):
   - Add family members (person menu at the top of Home).
   - "Update lock screen automatically": after saving the image, the app opens the Shortcuts app to run a shortcut named "ALDECARE壁紙" that the user adds once (the app shows the steps). If the shortcut has not been added, the Shortcuts app shows that it cannot find it; saving the image still works.
   - Home > いつもの体力: timed chair-stand, one-leg-stand and walking tests with a chart.

Native features used: photo library (to save the image to an "ALDECARE 救急情報" album), speech synthesis, StoreKit 2 in-app purchase, share sheet, phone call URLs, Shortcuts URL scheme.

Privacy: all user data stays on the device. The app has no server, no analytics and no ads, and makes no network requests except App Store purchases.
```
